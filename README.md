# ReliefNet

> AI-Powered Disaster Response & Emergency Resource Allocation Platform

🏆 Winner – HackVerse 2026

## Overview

ReliefNet is an AI-powered disaster response platform that assists emergency authorities in analyzing disaster incidents, allocating emergency resources, and coordinating rescue operations in real time.

The platform combines artificial intelligence, geospatial intelligence, and real-time synchronization to improve emergency response and support faster decision-making during critical situations.

---

## Key Features

- AI-assisted disaster analysis
- Intelligent severity assessment
- Smart resource allocation
- Real-time incident monitoring
- Interactive disaster mapping
- Live responder tracking
- Firebase-powered real-time synchronization
- Multi-agent emergency response workflow

## Installation

Clone the repository

```bash
git clone https://github.com/victorshreyas-svg/ReliefNet.git
```

Frontend

```bash
cd frontend
npm install
npm run dev
```

Backend

```bash
cd backend
npm install
npm start
```
